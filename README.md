# 星火 · 毛诗

> 打开，读一句毛诗；点进去，看它被写下时的处境。

星火是一个**离线**的毛泽东诗词阅读应用：随机一句完整诗 → 全诗 → 写作背景 → 基于材料的解读。无账号、无广告、无统计、零联网。

**形态**：手机宽度 Web（单页，可离线打开）+ Android APK（WebView 壳，同一套界面）。

## 快速体验

- **网页**：直接打开 `web/index.html`（无需服务器，file:// 即可；Chrome/Edge 推荐）
- **Android**：`pack/out/星火-1.0.0.apk`（自签名，覆盖安装升级）

90 秒走完三条路：**随机一句 → 搜索 → 点句进详情**。

## 为什么做

用户会忽然想起一句毛诗，但想不起全诗，也不知道当时为什么写。看懂一句诗需要三件事同时成立：诗本身、写作时的处境、基于材料的解读。星火把这三件事做成一个 63 首的窄而深的产品——**范围窄（只做毛诗）· 内容真（每段解读都可指回年谱/传记）· 体验静（无社区无算法）· 离线硬（断网可读）**。

## 功能

| 模块 | 能力 |
|---|---|
| 随机阅读 | 全库 63 首 303 行完整句：先等概率抽诗、再诗内抽句（每句都有机会上首页）；不重复上一句；返回保持原句 |
| 搜索 | 诗句片段 / 诗题，本地即时过滤 |
| 详情 | 全诗（整句一行，15px 正文不提前换行）、写作背景、诗词解读、材料出处，全部可溯源 |
| 收藏 | 整首 + 单句双轨收藏；管理模式（全选/删除） |
| 存图 | 竖屏长图（皮肤 + 背景图 + 手迹「星火」落款 + 全内容排版；字体与详情页一致），预览确认后保存，浏览器下载 / Android 直存相册 |
| 备份 | 收藏导出 JSON（确认 + 落点提示）/ 导入合并去重（严格校验 + 明细确认） |
| 搜索 | 诗句片段 / 诗题，本地即时过滤；搜索历史（10 条去重置顶、清除、点击重搜） |
| 设置 | 5 种字体（全本地 woff2）/ 12–24pt 字号 / 7 种皮肤 / 背景图 + 透明度（仅作用于首页诗句与详情页） |
| Android | 离线打包（Android 10+）、开屏页、状态栏随皮肤融合、存图直存相册、背景上传、返回键/左划手势按视图栈回退、字号不受系统字体缩放影响 |

## 内容体系（两层库）

```
素材库（编辑用，不进 App）          成品库（App 的数据）
年谱全九卷 / 传记 / 鉴赏              content/poems/<id>.json × 63
        ↓ AI 起草 + 人工审稿                ↓ kb.py 构建
        content/poems/*.json      →   web/data/poems.js（唯一进用户包）
```

- 写稿规则：背景只写材料里的事实；解读必须能指回出处；禁「年谱记载」字样；材料不足标注「资料未覆盖」，禁止 AI 补全
- 拆句规范：每行 = 一个完整句（句号/问号结尾），全库 303 行全部通过校验

## 技术栈

- **前端**：原生 HTML/CSS/JS 单页——零依赖、零构建、file:// 可跑
- **存图**：Canvas 两遍绘制（measureText 测高 → 绘制），DPR 2 高清；品牌图 dataURL 内嵌防 canvas 污染
- **Android 壳**：Java WebView + 原生桥（存图入相册 / 状态栏同步），aapt2 + d8 + apksigner 命令行构建（无 Gradle）
- **内容工具**：Python（EPUB 解析、品牌图生成、知识库构建）

## 目录结构

```text
web/                  应用本体（可直接打开的静态站）
  index.html          单页结构（全部视图）
  app.js              全部逻辑（零依赖）
  styles.css          皮肤/字体/布局
  data/poems.js       成品库（63 首，构建产物）
  fonts/              本地字体（woff2）
  brand.png           手迹「星火」品牌图
content/              内容源（成品库 JSON × 63）
tools/                内容管线（kb.py / build-material.py / make-brand.py …）
docs/                 产品与内容文档
pack/                 Android 打包工程（本地构建，不入库）
```

## 构建

```bash
# 内容库 → 网页数据
python tools/kb.py

# 品牌图 + dataURL 同步
python tools/make-brand.py

# Android APK（需本机 Android SDK 工具链）
node pack/build-apk.js    # 输出 pack/out/星火-1.0.0.apk
```

## 隐私

无账号、无收集、无统计、无广告、无第三方 SDK；设置与收藏只存本机，卸载即销毁；存图/导出/导入均由你主动触发。详见[隐私政策](docs/隐私政策.md)。
