# 毛诗 · 竞品分析

版本：v0.1（2026-08）｜用途：产品定位依据 + 面试素材

## 1. 分析框架

- **谁在解决同一个问题**：想起一句诗/一句语录，想了解全貌与背景
- **定位差异**：产品想成为的样子（毛诗 = 安静的阅读角落，不是金句大杂烩）
- **差异化结论**：不打价格战、不做功能堆叠，做「历史现场还原」

## 2. 竞品逐一

### 2.1 西窗烛（诗词 App 头部）

| 维度 | 观察 |
|---|---|
| 定位 | 中华诗词全库 + 每日一诗 + 创作分享社区 |
| 覆盖 | 全唐诗宋词元曲，数万首 |
| 内容 | 诗词 + 注释 + 赏析（多为百科体） |
| 功能 | 搜索、分类、卡片分享、社区、打卡 |
| 与我们 | 泛诗词平台，一首毛诗淹没在数万首里；无「写作现场」叙事 |

**启示**：① 卡片分享做得好（用户愿意传播）——我们的存图功能对标它；② 社区不是必需品——我们不做。

### 2.2 问问毛选（同题材竞品，已反编译研究其数据）

| 维度 | 观察 |
|---|---|
| 定位 | 毛选文章金句 + 现代应用 |
| 内容 | quotes.json 约 200 条金句，每条 = 金句 + 出处 + 背景 + **「启示我们：职场……」** |
| 模式 | 金句卡片流 |
| 与我们 | 同题材，**内容策略完全相反** |

**关键差异（我们的机会）**：
- 它的背景是 AI 生成的概述（无出处、有「启示我们：职场中……」鸡汤），我们 PRD 明确**禁止**职场建议与心灵鸡汤
- 它做文章金句，我们做诗词 + 历史现场（时间、地点、当时在做什么）
- 它不展示全诗，我们点进去看全诗
- 面试可直接讲：我研究过同题材 App，它的内容策略（AI 概括 + 鸡汤启示）正是我不做的——我们只写能指回年谱/传记的事实与解读

### 2.3 古诗文网（Web 端）

| 维度 | 观察 |
|---|---|
| 定位 | 古诗文全库 + 译文注释（UGC 众包） |
| 内容 | 有毛诗全库和注释，但无「这首诗写作时的历史处境」的叙事 |
| 模式 | 传统文库搜索 |

**启示**：素材源头可参考其注释，但产品形态过时（门户式），不构成威胁。

## 3. 竞品对比表

| | 西窗烛 | 问问毛选 | 古诗文网 | **毛诗（我们）** |
|---|---|---|---|---|
| 范围 | 全诗词 | 毛选金句 | 全古诗文 | **毛诗 63 首** |
| 随机入口 | 每日一诗 | 卡片流 | 无 | **随机完整句** |
| 写作背景 | 百科式注释 | AI 概述 | 无/简注 | **年谱+传记还原历史现场** |
| 解读 | 赏析文 | 鸡汤启示 | 译文 | **材料驱动的写法解读** |
| 离线 | 部分 | 是 | 否 | **全离线** |
| 社区/登录 | 有 | 无 | 有 | **无** |

## 4. 差异化结论（写进 PRD 的依据）

1. **范围做窄**：只做毛诗，63 首做深（每首有历史现场）——窄而深，不宽而浅
2. **内容做真**：每个背景、每段解读都能指回年谱/传记；同题材竞品（问问毛选）的 AI 概述 + 鸡汤恰恰是我们明确不做的
3. **体验做静**：无社区、无登录、无信息流；打开即一句
4. **离线做硬**：全本地，断网可读（竞品多数做不到）

## 5. 面试口径（90 秒讲竞品）

> 我做这个产品前研究了三个竞品：西窗烛做全诗词平台（社区+打卡，毛诗淹没其中）；问问毛选做毛选金句（背景是 AI 概括、还带"启示我们职场……"的鸡汤）；古诗文网是传统文库。我的差异化是：范围只做毛诗 63 首，每首还原"写这首诗时的历史现场"（年谱+传记），解读只写能指回材料的，明确不做鸡汤和职场启示——所以我的背景和解读每一段都有出处。
