# 星火 · 产品脑图

> 大纲结构，可直接导入 XMind（Markdown 大纲）或按层级重画。根节点：星火 App。

## 星火 App

### 1. 产品定位
- 一句话：随机一句毛诗 → 全诗 + 历史现场 + 材料解读
- 目标用户：自己（第一用户）
- 差异化：范围窄（63 首）· 内容真（有出处）· 体验静（无社区）· 离线硬
- 不做：登录/社区/AI 问答/鸡汤启示

### 2. 核心功能
- 首页
  - 随机完整句（句号单位，防重复）
  - 换一句（右侧主按钮，拇指热区）
  - 搜索（左侧次按钮）
  - 两行小字：作品名 + 中文日期
- 详情
  - 全诗
  - 写作背景（时/地/事件）
  - 诗词解读（写法与处境）
  - 材料出处
- 收藏 / 存图
- 阅读设置
  - 字体 5 种
  - 字号 12–24pt 滑块
  - 皮肤 7 纯色（含绛红烫金）
  - 背景图片 + 透明度

### 3. 界面设计
- 首页：顶部断口金线 + 五角星（引首章意象）
- 布局：手机宽 390，主行动在右
- 原则：点缀不包围；安静阅读

### 4. 内容体系
- 素材库（编辑用）
  - 年谱：年/日期/条目
  - 传记：章节/段落
  - 鉴赏：63 首索引
- 成品库
  - content/poems/<id>.json × 63
  - 写稿规则：禁「年谱记载」、禁现编、缺料标注
- 构建管线：kb.py → web/data/poems.js

### 5. 数据规范
- lines：每行一联、句号结尾、必须完整
- excerpt：代表句（可选，兜底 lines[0]）
- 律诗 4 行 / 绝句 2 行

### 6. 版本规划
- V1（现在）：网页 + 15–25 首内容 + 文档
- V2：Android 打包 + 小组件（每日一句）
- V3（待定）：按年浏览、发布渠道

### 7. 面试叙事
- 问题 → 调研（竞品） → 定位 → 原型 → 内容管线 → 验证
- 90 秒演示：随机 → 搜索 → 详情
