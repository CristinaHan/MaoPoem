# 星火 · 产品脑图 v1.0

> 大纲结构，可直接导入 XMind（Markdown 大纲）或按层级重画。根节点：星火 App。

## 星火 App

### 1. 产品定位
- 一句话：随机一句毛诗 → 全诗 + 历史现场 + 材料解读
- Slogan：打开，读一句毛诗
- 目标用户：自己（第一用户）→ 毛诗爱好者
- 差异化：范围窄（63 首）· 内容真（有出处）· 体验静（无社区）· 离线硬（零联网）
- 不做：登录 / 社区 / AI 问答 / 鸡汤启示 / 广告 / 统计 SDK

### 2. 信息架构
- 首页
  - 随机完整句（句号单位，先等概率抽诗再抽句，每句都有机会）
  - 作品名 + 中文数字日期（两行小字）
  - 换一句（右侧主按钮）/ 搜索（左侧次按钮）
- 搜索
  - 输入框：诗句片段 / 诗题
  - 结果列表：标题 + 代表句
- 详情
  - 标题（多行完整展示，跟随字体）
  - meta：日期 · 于地点
  - 全诗（整句一行，15px，七绝七律不提前换行）
  - 写作背景（事实，可溯源）
  - 诗词解读（写法与处境）
  - 材料出处（底部小字）
  - 操作：收藏（星标）/ 存图（竖屏长图）
- 我的
  - 收藏（双 Tab：全诗 / 单句；管理模式：全选 / 删除）
  - 导出收藏（JSON 备份，显示条数）
  - 导入收藏（JSON 恢复，合并去重）
  - 设置四行：字体 / 字号 / 皮肤 / 背景
  - 关于：隐私政策 / 帮助 / GitHub / 邮箱反馈
- 设置子页
  - 字体：宋体 / 楷体 / 仿宋 / 黑体 / 汇文明朝
  - 字号：滑块 12–24pt（1pt 步进，实时显示）
  - 皮肤：米白 / 素白 / 豆沙绿 / 暖棕 / 浅灰 / 夜读黑 / 绛红
  - 背景：无 / 上传图片（透明度 10–70% 滑块）

### 3. 核心功能
- 随机阅读（F1/F2）：完整句抽取、防重复、返回保持原句
- 搜索（F3）：本地即时过滤
- 收藏（F9）：整首 + 单句双轨、管理、迁移
- 存图（F10）：竖屏长图 = 皮肤底色 + 背景图 + 手迹星火落款 + 全内容排版；浏览器下载 / Android 存相册
- 备份（F11）：导出 JSON / 导入合并去重 / 严格校验
- 设置（F12）：字体 / 字号 / 皮肤 / 背景，四维可调
- Android 壳（F13）：离线打包、存图桥、状态栏融合、textZoom 固定

### 4. 界面与视觉
- 首页：顶部断口金线 + 五角星（引首章意象）
- 品牌：手迹「星火」抠图（白底黑字 → 透明底品牌红 #8b1e1e）
- 布局：手机宽 390 设计；主行动在右（拇指热区）
- 原则：点缀不包围；安静阅读；字号与主流阅读应用一致（详情正文 15px）
- Android：状态栏随皮肤融合（深色皮肤自动白字图标）

### 5. 内容体系
- 素材库（编辑用，不进 App）
  - 年谱全九卷：年 / 日期 / 条目
  - 传记：章节 / 段落
  - 鉴赏：63 首文章（toc 已索引）
- 成品库
  - content/poems/<id>.json × 63（字段：order/id/title/form/date/place/originalTitle/excerpt/lines/searchText/complete/background/interpretation/sources）
  - 写稿规则：禁「年谱记载」字样、禁 AI 现编、缺料标注「资料未覆盖」、后见之明独立成段
- 构建管线
  - build-material.py：EPUB → 素材库
  - AI 起草 + 人工审稿 → content/poems/
  - kb.py → web/data/poems.js（只有这份进用户包）
  - make-brand.py → brand.png + brand-data.js（dataURL，canvas 防污染）

### 6. 数据与存储
- 内容：web/data/poems.js（63 首 303 行，全部完整句）
- 收藏：localStorage（结构化记录：id/lineIndex/kind/time，老数据自动迁移）
- 偏好：字体/字号/皮肤/背景/透明度（旧档位自动迁移）
- 备份：JSON 文件（导出下载 / 导入合并）

### 7. 技术栈
- 前端：原生 HTML/CSS/JS 单页（零依赖、零构建、file:// 可跑）
- Canvas 存图：measureText 测量 + 两遍绘制（测高 → 绘制），DPR 2
- Android：WebView 壳（Java，aapt2/d8/apksigner 命令行构建，无 Gradle）
  - XingHuoBridge：saveImage（MediaStore 存相册）/ setTheme（状态栏同步）
  - 工程注意：R8 8.2.2 + JDK22 对匿名类/非静态内部类有 NPE bug → 只用 static 内部类与命名类
- 内容工具：Python（Pillow 图像处理 / EPUB 解析）
