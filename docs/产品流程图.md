# 星火 · 产品流程图

> mermaid 语法，可粘贴到 https://mermaid.live 渲染，或照着画进 Visio/ProcessOn。

## 1. 用户主流程（App 内）

```mermaid
flowchart TD
    A[打开应用] --> B{随机抽一句完整句}
    B --> C[首页展示<br/>句 + 作品名 + 日期]
    C -->|换一句| B
    C -->|搜索| D[输入关键词]
    D --> E{命中?}
    E -->|是| F[结果列表]
    E -->|否| G[提示换词再搜]
    F --> H[点结果进详情]
    C -->|点句子| H
    H --> I[详情页<br/>全诗 + 背景 + 解读 + 出处]
    I -->|收藏| J[星标收藏]
    I -->|存图| K[生成卡片图片]
    I -->|返回| C
    C -->|齿轮| L[设置页]
    L --> M[字体/字号/皮肤/背景]
    L -->|我的收藏| N[收藏列表]
    N --> H
```

## 2. 内容生产流程（编辑侧，不进 App）

```mermaid
flowchart LR
    A[三本 EPUB 解压] --> B[解析器 tools/build-material.py]
    B --> C[素材库<br/>年谱条目 + 传记章节 + 鉴赏索引]
    C --> D[材料包装配<br/>按诗写作时间取同期材料]
    D --> E[AI 起草背景+解读<br/>约束：只用包内材料]
    E --> F[人工审稿<br/>查事实/禁鸡汤/禁出处字眼]
    F --> G[content/poems/&lt;id&gt;.json]
    G --> H[kb.py 构建]
    H --> I[web/data/poems.js]
    I --> J[App 打包/网页发布]
```

## 3. 用户主流程的决策点（面试可讲）

1. **随机还是按顺序**：随机——每个句子都有机会被看见；防重复（不连续同诗同句）
2. **换一句在右**：右利手拇指热区，主行动最易触达
3. **返回保持原句**：详情/搜索/设置返回首页不换句——用户的心理模型是「回来看刚才那句」
4. **皮肤 = 整套配色**：不做独立字体颜色功能（职责重叠，冲突无从裁决）
