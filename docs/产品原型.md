# 星火 · 产品原型 v1.0

> 低保真线框（ASCII）+ 交互标注。手机宽 390px 设计，电脑端居中手机框展示。
> 版本对齐：PRD v1.0（一期全量交付，2026-08-30）。

---

## 1. 首页（view-home）

```
┌─────────────────────────────┐
│  ────────★────────          │ ← 引首章：金色断口横线 + 半空心五角星
│                             │
│                             │
│   天生一个仙人洞，           │
│   无限风光在险峰             │ ← 随机完整句（按逗号拆短行，居中大字）
│                             │
│   《七绝·为李进同志题       │ ← 作品名（小字）
│   所摄庐山仙人洞照》          │
│   一九六一年九月             │ ← 中文数字日期（小字）
│                             │
│                             │
│                             │
│  ┌───────┐      ┌────────┐  │
│  │ 搜索   │      │ 换一句  │  │ ← 左：次行动（48px） 右：主行动（拇指热区）
│  └───────┘      └────────┘  │
└─────────────────────────────┘
```

**交互**
- 打开：随机抽一句完整句（先等概率抽诗、再诗内抽句，每句都有机会；不重复上一句）
- 点句子 → 详情；点「换一句」→ 抽下一句（不连续同诗同句）
- 右上角星标：收藏当前句（星标点亮切换）
- 从详情/搜索/设置返回：**保持刚才那句**（不换句）

## 7. Android 壳（APK 专属差异）

- 启动：开屏页（品牌图 + 星火 + 版本号，约 1.8s 淡出）→ WebView 加载本地 assets（无启动网络）
- 状态栏：颜色随皮肤融合（深色皮肤自动白字图标）
- 存图：直存系统相册（原生 Toast「已保存至本地相册」，失败 JS 提示原因）
- 字号：textZoom 固定 100（不受系统字体大小设置影响）
- 图标：米白底 + 紧凑版手迹星火（五档密度）
- 返回：返回键/左划手势按视图栈回退（详情→来源、设置→我的、首页→退出）；弹层开着先关弹层
- 背景上传：系统文件选择器（onShowFileChooser 桥）
- 导出收藏：写入系统「下载」目录，提示「下载/文件名」

## 9. 设计规范速查

| 项 | 规格 |
|---|---|
| 设计宽度 | 390px（电脑端居中手机框） |
| 主按钮 | 48px 高（可用性底线） |
| 详情正文 | 15px（七律整句 ≈250px，窄屏不换行） |
| 详情标题 | 18px（> 正文，多行完整展示） |
| 首页大字 | 32px（随字号滑块缩放） |
| 品牌红 | #8b1e1e（手迹星火） |
| 金色装饰 | #b0894a（引首章/框线） |
| 默认纸色 | #f4efe4（米白皮肤） |
| 皮肤数 | 7（米白/素白/豆沙绿/暖棕/浅灰/夜读黑/绛红） |
| 字体数 | 5（宋/楷/仿宋/黑/汇文明朝，全本地 woff2） |
| 存图 | 竖屏 780×auto @2x（物理 1560 宽） |
| 存图预览弹层 | 预览图 max-height 65vh，弹窗居中顶层 |
