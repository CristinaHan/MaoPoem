## 1. 一句话

打开随机一句毛诗（完整句，不是半句），或搜到自己想起的那句；点进去看到全诗、这首诗被写下时的处境，以及基于材料的解读。

## 2. 要解决的问题

用户会忽然想起一句毛诗，但想不起全诗，也不知道当时为什么写。要三件事同时成立：

1. 诗本身长什么样（全诗、完整句子）
2. 写作时的背景与情境
3. 基于材料的解读：这首诗是怎么写成的

## 3. 目标与不抢

| 对象 | 关系 |
|---|---|
| 自己 | 第一用户。先做自己会反复打开的那批诗 |
| 西窗烛 | 不抢。他们做全诗词检索；我们只做毛泽东的诗 |
| 问问毛选 | 姐妹，不换皮。他们做毛选文章金句 + 现代应用；我们做毛诗 + 历史现场 |
| 古诗文网 | 不抢。他们做古诗文全库 + 注释；我们做「这句诗当时为什么写」 |

不做：登录、社区、评论、个性化推荐、AI 问答。

## 4. 成功标准（第一期）

- 打开就能读到一句，且是完整句（律诗一联、词一句）
- 换一句、搜索、进入详情，三条路都通
- 每次打开/换一句，拆出的句子随机、不重复上一句
- 详情页稳定出现：全诗 / 写作背景 / 诗词解读
- 每一段背景和解读都能指回本地年谱或传记
- 离线可用（字体、数据全本地）
- 面试官能 90 秒走完：随机 → 搜索 → 详情三块

## 5. 用户路径

```text
打开应用
    → 随机显示一句（完整句号单位，从全诗 lines 随机拆）
        → 换一句：再随机一句（不重复诗；同诗不重复句）
        → 搜索：按诗句或诗题找回
        → 点这句：进入详情
            → 全诗
            → 写作背景（何时、何地、当时在做什么）
            → 诗词解读（这首诗如何写成）
```

返回语义：从详情/搜索/设置返回首页，**保持刚才那句**（不换句）。

## 7. 内容与数据需求

### 7.1 两层库（v0.2 定稿）

```
第1层 素材库（编辑用，不进 App）          第2层 成品库（App 真正用的「数据库」）
年谱全九卷 → 年/日期/条目                  content/poems/<id>.json
传记 → 章节/段落                          63 首，每首一个文件：
鉴赏 → 63 首诗的文章（toc 已索引）          全诗/背景/解读/出处
        ↓ 写稿（AI 起草 + 人审）
        content/poems/*.json
        ↓ kb.py 构建
        web/data/poems.js   ← 只有这份进用户包
```

### 7.2 拆句规范（v0.2 新增）

- `lines` 每行一句（一联），**句号结尾，必须完整**；首页按行（句号单位）随机抽取，每句都有机会上首页
- 律诗 8 个单句 → 4 行（每行一联）；绝句 4 个单句 → 2 行；词按自然句
- 禁止半句（如单独「满街红绿走旌旗」）——那是回忆不起上句时的示例，正式库必须给完整联
- `excerpt`（代表句）可选，用于搜索/收藏列表；留空时程序自动取 `lines[0]` 兜底

### 7.3 写稿规则

- 背景：事实。不升华，不写「启示我们」
- 解读：说明写法与处境的关系，仍须能指回材料
- 叙述是合成文字，禁止「年谱说 / 传记记载 / 鉴赏写道」等字样
- 日期用阿拉伯数字（首页展示转中文数字）
- 材料不足的字段写「资料未覆盖」，禁止 AI 补全
- 后见之明标在解读末段，不混进写作当时
- 收录范围：先做可被年谱对上时间的诗（建议 15–25 首打通），再逐步补到 63

### 7.4 依赖

data/ 下三本书（epub 已解压）：诗词全编鉴赏、年谱全九卷、毛泽东传。已齐。

## 8. 界面规范（v0.2 冻结）

### 8.1 首页视觉：引首章设计

- 顶部一条金色断口横线（2px），断口中央一枚半空心五角星（外纸色描金 + 内嵌金星）
- **无侧边框、无底边框**（完整框 + 按钮组合会拥挤且像「奖状」；顶线意象是书法立轴的引首章）
- 星与线端各留 10px 空隙；线中心与星心对齐
- 诗句下方两行小字：作品名《…》 + 中文数字写作日期
- 设计决策记录：装饰的任务是点缀不是包围；纠结时用「产品想成为的样子」过滤

### 8.2 布局与拇指热区

- 手机宽度 390px 设计；电脑打开居中手机框
- 主行动「换一句」在**右侧**（右利手拇指热区），次行动「搜索」在左侧
- 按钮高度 48px（可用性底线，不缩）
- 设置入口：右上角齿轮图标（平台惯例，位置不动、去文字噪音）

### 8.3 阅读设置（颗粒度）

| 维度 | 规格 |
|---|---|
| 字体 | 5 种：宋体 / 楷体 / 仿宋 / 黑体 / 汇文明朝（本地 woff2） |
| 字号 | 连续滑块 **12–24pt**（1pt 步进，实时显示当前值；旧档位自动迁移） |
| 皮肤 | **7 个纯色**：米白 / 素白 / 豆沙绿 / 暖棕 / 浅灰 / 夜读黑 / 绛红（烫金） |
| 背景 | 无 / 上传图片（透明度滑块 10–70%，显示百分比） |

- 皮肤 = 整套配色（背景 + 正文 + 强调 + 装饰）；**不做独立「字体颜色」功能**——与皮肤职责重叠，冲突时无从裁决（微信读书同思路）
- 皮肤选择器：圆形色块调色盘（显示实际颜色 + 名称 tooltip）

### 8.4 内容展示

- 详情：全诗居中、宋体排印；「写作背景」「诗词解读」分节；出处小字在底部
- 首页句子：完整联按逗号/分号拆成短行，大字居中

## 9. 非功能

| 项 | 要求 |
|---|---|
| 离线 | 数据打进包内或本地静态文件，打开即可读（字体已本地化） |
| 性能 | 搜索本地完成，输入即出结果 |
| 版权 | 个人作品与学习用途；上线前核对诗词、年谱、传记与字体（Huiwen-mincho 公有领域待附说明；柳建毛草已于 v1.1 移除） |
